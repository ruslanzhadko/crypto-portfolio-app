# Статистика торговли — план (решения владельца 29.10.2026)

Цель: видеть результат торговли за день, неделю, месяц по закрытым позициям и получать итог дня в Telegram.
Отдельного пункта меню нет: вкладка на странице «Позиции».

## 1. Данные

- Новая таблица закрытых сделок (миграция только добавляет): пользователь, подключение (счёт), биржа, монета,
  лонг/шорт, объём, цена входа и выхода, время открытия и закрытия, длительность, итог в $ (с фандингом и
  комиссиями), признак «точно / ≈», источник (`watch` — замечено worker, `ledger` — загружено из журнала биржи).
- **Запись закрытий:** worker пишет каждое полное закрытие, которое видит при синхронизации, независимо от
  настроек уведомлений. Итог — тот же расчёт, что в сообщении о закрытии (`lib/positions/alert-service.ts`,
  `resolveClosed`): точный из журнала биржи для Binance, Bybit, BingX, Aster API, иначе «≈».
  Одна запись в БД на закрытие, без отдельного опроса (бюджет Neon).
- **Загрузка истории (решение 29.10):** где биржа позволяет, подтянуть закрытые сделки за прошлый месяц,
  чтобы статистика не начиналась с нуля. Binance, Aster API, BingX — `income` (REALIZED_PNL, FUNDING_FEE,
  COMMISSION); Bybit — `closed-pnl` (по сделкам, с ценами входа/выхода) и `transaction-log`. Из журналов
  income получаются суммы по монете и времени без цен входа — такие строки помечаются источником `ledger`.
  Один раз на подключение, потом новые закрытия пишет worker. Повтор загрузки не создаёт дублей
  (уникальный ключ — биржевой id или монета + время закрытия).
- Частичные закрытия пока не считаются (как в уведомлениях).

## 2. Страница «Статистика»

- Переключатель вверху страницы «Позиции»: **Открытые | Статистика** (`/positions?tab=stats`).
- Период: Сегодня / 7 дней / 30 дней / Всё / свой диапазон.
- **Фильтры:** биржа, счёт (подключение), монета, лонг/шорт, точные/все; совместная статистика всех счетов
  по умолчанию и отдельно по каждому.
- Карточки: итог в $, число сделок, доля прибыльных, средняя прибыль и средний убыток, комиссии и фандинг,
  лучшая и худшая сделка, средняя длительность.
- График итога по дням (столбики плюс/минус) и накопленный итог.
- Разбивка по биржам, счетам и монетам (таблицы с итогом и числом сделок).
- Таблица закрытых сделок: монета, сторона, вход → выход, длительность, итог; сортировка и фильтры.

## 3. Итог дня в Telegram

- Переключатель «Итог дня» на странице «Уведомления», вкладка «Позиции».
- Worker после 00:00 по Киеву отправляет итог за прошедшие сутки только по закрытым позициям:
  итог в $, сделок (✅/❌), лучшая и худшая, комиссии и фандинг, ссылка на статистику.
- Нет закрытых сделок — сообщения нет. Запись в журнал уведомлений, как у остальных.
- Позже: итог недели по воскресеньям.

## 4. Этапы

1. Таблица сделок, запись закрытий worker, загрузка истории за месяц, вкладка «Статистика» с фильтрами.
2. Итог дня в Telegram и переключатель в настройках.
3. Итог недели, частичные закрытия, экспорт CSV.
