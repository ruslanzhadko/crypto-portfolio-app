# Подключение Bitget

В приложении откройте «Биржи» → «Подключить биржу» → Bitget. Один ключ подключает спот и фьючерсы одного аккаунта. Режим определяется автоматически: выбирать Classic или Unified в приложении не нужно.

1. В Bitget создайте API-ключ и задайте Passphrase. Это пароль самого API-ключа, а не пароль входа на биржу.
2. Выберите только чтение. Для Classic нужны права чтения спота и фьючерсных позиций/счёта. Для Unified нужны **UTA management (read)** и **UTA trade (read)**. Не включайте торговлю, переводы и вывод средств.
3. Привяжите ключ к IP сервера, указанному в форме подключения приложения.
4. Введите API key, API secret и Passphrase, затем сохраните подключение. Проверку и дальнейшую синхронизацию выполняет сервер.

## Что отображается

- **Classic:** отдельный спотовый баланс и фьючерсные счета USDT/USDC. Нереализованный PnL уже входит в капитал фьючерсного счёта и повторно не прибавляется.
- **Unified:** один общий капитал аккаунта, состав активов и позиции. Спот и фьючерсы используют общий пул; складывать их как отдельные балансы нельзя.
- Для открытых линейных позиций: размер, вход, маркировка, плечо, режим маржи, ликвидация, реализованный/нереализованный PnL, накопленный funding, торговые комиссии и следующий funding.
- Funding и комиссии берутся из данных позиции Bitget. Если биржа не вернула поле, приложение показывает «—», а не предполагаемый ноль.
- При смене режима полный успешный снимок заменяет предыдущие счета. При ошибке API последние известные значения сохраняются.

Отдельный Funding wallet, Earn и обратные COIN-M контракты пока не входят в поддерживаемый набор. Обнаруженная COIN-M экспозиция вызывает сообщение об ограничении поддержки; она не учитывается как нулевой баланс.
